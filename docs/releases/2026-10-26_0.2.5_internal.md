# BYOKey Speak 0.2.5 内部テスト用リリース

確認日: 2026-10-26

## 変更

- ヘルプとAboutはバージョン名だけを表示し、括弧内のversionCode表示を外した。
- オート読み上げのコールバックに、チャットIDと実際の返信メッセージIDを別々に渡すよう修正した。新規返信では保存時に返されたIDを使い、オートをオンにした際の再再生では対象返信のIDを使う。
- 読み上げ後の自動マイクは、対象メッセージの完了を確認したうえで元のチャットに対して起動する。停止・エラー時は両方の待機IDを解除する。
- バージョンは`0.2.5`、versionCodeは`14`、パッケージは`com.byokeylab.speak`とする。

## 原因

以前のオート読み上げは、チャットIDを再生中メッセージIDとして扱っていた。一方、返信のアイコンはメッセージIDとの一致で表示を切り替える。この2つのIDが異なると、実際には再生中でもスピーカーのままになっていた。

## 検証

- 別件の未コミット変更を含めず、公開済み`f3f69a9`を基点にした独立作業ツリーでビルドした。
- 全単体テスト: 13スイート59件成功。失敗・エラー・スキップは0件。
- Debug APK、Release AAB、Release Lint: 成功。
- エミュレーターの新規Debugパッケージを用い、チャットID`1001`、返信メッセージID`2000`と`2001`という異なるIDを持つテストデータで確認した。
- オートをオンにした直後の再生で、最新返信だけが一時停止アイコンになり、古い返信はスピーカーのままであることを確認した。
- 新規に保存された返信の自動再生でも一時停止アイコンに切り替わることを確認した。
- 一時停止アイコンで再生が止まり、スピーカーに戻ること、停止後に自動マイクが起動しないことを確認した。
- 手動再生・停止も従来どおり動くことを確認した。
- ヘルプとAboutは`バージョン 0.2.5-debug`と表示され、括弧内の番号がないことを確認した。Release版では`バージョン 0.2.5`になる。

UI試験の音声はキャッシュに置いたテスト用無音PCMである。新規返信の経路確認には架空のAPIキーによる会話生成失敗時の返信を使った。実APIでの音声生成や実音声によるマイク入力は実施していない。

## 内部テストでの確認

1. ヘルプまたはAboutの表示が`バージョン 0.2.5`であること。
2. オート機能で返信の読み上げが始まると、右上のアイコンが一時停止になること。
3. そのアイコンを押して再生を止められること。
4. 生成待ちの回転表示が引き続き動くこと。
