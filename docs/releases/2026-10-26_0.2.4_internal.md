# BYOKey Speak 0.2.4 内部テスト用リリース

確認日: 2026-10-26

## 変更

- ヘルプとAboutに、`BuildConfig.VERSION_NAME`と`VERSION_CODE`に連動したバージョン表示を追加した。
- Gemini音声の生成待ちに、回転するインジケーター、「音声を生成中…」、停止ボタンを表示する。
- 生成開始の通知はキャッシュがない場合にだけ行う。最初の音声の再生開始、エラー、手動停止で待機表示を消す。
- 停止後の古いコールバックは、既存の再生シーケンス判定により受け付けない。
- バージョンは`0.2.4` / `versionCode 13`、パッケージは`com.byokeylab.speak`とする。

## 検証

- 元の作業ツリーにある別件の未コミット変更を除き、公開済み`5fbf321`から独立した作業ツリーでビルドした。
- 全単体テスト: 13スイート59件成功。失敗・エラー・スキップは0件。
- Debug APK、Release AAB、Release Lint: 成功。
- Pixel 10のread-onlyエミュレーターで画面を確認した。ライト・ダークテーマ、幅360dp、キーボード表示中のレイアウトを確認した。
- ヘルプとAboutで`0.2.4-debug (13)`が表示されることを確認した。製品版にはReleaseビルドのバージョン値が表示される。
- 生成待ちの連続スクリーンショットで、回転インジケーターの描画が変化することを確認した。
- 生成の停止後と通信失敗後に待機表示が消えることを確認した。
- キャッシュ済みのテスト用PCM再生で生成中表示が出ないことを確認した。

生成待ちと通信失敗の試験には架空のテスト用キーと待機する通信経路を使用した。キャッシュ再生の試験音声はテスト用の無音PCMである。今回のUI検証で実APIによる音声生成は行っていない。

## 内部テストでの確認

1. ヘルプまたはAboutで`0.2.4 (13)`と表示されること。
2. キャッシュのない返信をGemini音声で読み上げ、最初の音声が出るまで待機表示が動くこと。
3. 生成待ちの停止ボタンで処理を取り消せること。
4. 音声の再生開始後は待機表示が消えること。

実端末への更新反映と、実APIを使用した音声との連動は利用者による内部テストの確認対象である。
