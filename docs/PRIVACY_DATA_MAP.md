# プライバシーデータマップ

更新日: 2026-07-20

## データフロー

| データ | 保存先 | 送信先 | 用途 |
| --- | --- | --- | --- |
| APIキー | 端末内、AES-GCM暗号化 | 選択したLLMプロバイダー | API認証 |
| 会話本文 | 端末内 | 選択したLLMプロバイダー | 会話生成と添削 |
| コーチ設定 | 端末内 | 選択したLLMプロバイダー | 応答スタイルの指定 |
| CEFRレベル | 端末内 | 選択したLLMプロバイダー | 応答難易度の指定 |
| 学習メモ | 端末内 | 送信しない | 復習 |
| ストリーク | 端末内 | 送信しない | 継続の見える化 |

BYOKey Labの運営サーバー、独自データベース、アクセス解析サービスへの送信は現時点で実装していない。

## 端末内の保護

- APIキー暗号鍵はAndroid Keystoreで生成する。
- 暗号方式はAES-256-GCMとする。
- APIキーをURLクエリ、ログ、例外本文へ出力しない。
- Androidのアプリデータバックアップを無効にする。
- 全通信をHTTPSに限定し、平文HTTPを禁止する。

## 外部事業者

ユーザーが選択した場合のみ、次の事業者へ会話本文とコーチ設定を直接送る。

- Google Gemini API
- OpenAI API
- Anthropic Claude API

各事業者のデータ保持、学習利用、地域、年齢、禁止用途、料金条件は各事業者の規約に従う。
アプリ内とプライバシーポリシーで、送信前にこの点を明示する必要がある。

## Play Data safetyの確認方針

Play Consoleの申告は、公開時点のコードと各SDKの仕様を基準に確定する。
第三者LLMへの送信がGoogle Play上の「共有」に該当するかは、Data safetyの定義と例外条件を公開直前に再確認する。
運営側でデータベースを持たないことだけを理由に「収集なし」と断定しない。
